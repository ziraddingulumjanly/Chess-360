Cookie Policy

A plain-language explanation of cookies and local browser storage.

As implemented in this version: The application does not set cookies or use cookie-based advertising/analytics.

Cookies

Chess 360's client-side code does not create any cookies. Website hosting or future external services may introduce their own cookies; this document must be updated if those services are added.

Local storage is different

The game uses browser localStorage rather than cookies to remember the game in progress, gameplay statistics, settings and recent completed games. These values are not transmitted automatically to the website server by the application's game logic.

Change or remove saved data

Clear site data for Chess 360 in your browser to remove locally saved games and preferences. Blocking or clearing site storage may disable saving across visits, but normal gameplay can still function within a session.

Updates

This page describes the supplied application. It should be revised if analytics, accounts, advertisements or other cookie-dependent services are introduced.
